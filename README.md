# comunio-app-data

Datos públicos (JSON) de la app móvil de la liga privada de Comunio. Solo
contiene los ficheros agregados que consume la app — sin credenciales, sin
lógica de scraping. El código y las credenciales viven en el repo privado
`comunio-scraper`.

Los ficheros de `data/` se sobrescriben automáticamente en cada ejecución
del scraper (~05:00, 08:00, 15:00 y 23:00 UTC) — no editar a mano.
